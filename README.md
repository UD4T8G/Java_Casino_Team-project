# Java_Casino_Team-project(자바 카지노 조별과제)

> **"자바 카지노에 오신 것을 환영합니다! 당신의 운을 시험해 보세요."**

자바(Java)로 구현한 미니 카지노 시스템입니다. 터미널(콘솔) 환경에서 다양한 미니 게임과 베팅을 즐길 수 있습니다.

## Games(게임)

자바 카지노에서는 두 게임장에서 총 4가지의 게임을 제공합니다.

* game1(게임장 1)
  * **SlotMachine(슬롯머신):** 레버를 당기세요! 같은 그림이 맞춰지면 배당금을 얻습니다.
  * **BlackJack(블랙잭):** 딜러와의 두뇌 싸움! 카드의 합을 21에 가장 가깝게 만들어보세요.
* game2(게임장 2)
  * **Horse(경마):** 트랙을 달리는 말들 중 가장 빠른 말에 베팅하여 상금을 노려보세요.
  * **Lottery(복권):** 일확천금의 기회! 행운의 숫자들을 맞추고 인생 역전을 경험하세요.

## Team Roles(팀원 및 역할 분담) 

각자의 주특기를 살려 카지노의 다양한 구역을 전담하여 개발했습니다.

| 이름 | 역할 | 담당 업무 |
| :--- | :--- | :--- |
| **[조장]** | **메인 시스템** | 카지노 로비 구현, 유저 소지금 관리, 게임 간 화면 이동 및 통합 흐름 제어 |
| **[UD]** | **클래식 카지노** | 슬롯머신, 블랙잭 게임 로직 및 베팅 시스템 구현 |
| **[팀원2]** | **레이싱 & 복권** | 경마 진행 로직, 복권 번호 추첨 및 당첨금 정산 로직 구현 |

## Tech Stack(사용 기술)
*   **Language:** Java (JDK [21])
*   **IDE:** [Eclipse]

## 실행 방법 (How to Play)
1. 프로젝트를 클론합니다.
2. `[Main.java]` 파일을 실행합니다.
3. 초기 자본금을 받고 원하는 게임을 선택하여 플레이합니다!
